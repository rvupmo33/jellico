### Getting Started

a. &nbsp;Clone the Repository:

```bash
git clone https://github.com/rvupmo33/jellico.git
```

b. &nbsp;CD Into Frontend and Install Dependencies:

```bash
cd frontend/
npm install
```

c. &nbsp;CD Into Backend and Install Dependencies:

```bash
cd backend/
npm install
```

d. &nbsp;Create a '.env' file in the root directory of the project and add PORT & MONGO_URI:

```bash
PORT=3000
MONGO_URI=<enter here>
```

d. &nbsp;Run the Project (do for both backend and frontend):

```bash
npm run dev
```
